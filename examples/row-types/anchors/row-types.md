# A constructed testbed for the row types

This file is the anchor source for the constructed demonstration. It is not a
measurement of any library. Each sentence below is the registered sentence of
one claim.

The reference sentence: the measured value is within 1e-6 relative of the reference on [0, 2].

The consistency sentence: the fast path is within 1e-12 of the scalar path on [0, 2].

The exactness sentence: the zero-argument return is exactly 1.

The vacuity sentence: the absolute bound is 1e-2 on values of order 1e-3.

The stated-domain sentence: the reference bound of 1e-6 holds over the stated sub-domain [0, 1].

The absent sentence: the sweep that would measure this claim is not in this tree.

The not-carried sentence: the vector seam that this claim sits behind is closed in this build.

The not-judged sentence: the figure is the shipped build's, and this build's defaults are a replacement's.
