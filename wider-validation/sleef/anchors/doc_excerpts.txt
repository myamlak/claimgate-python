sin: These functions evaluate the sine function of a value in a. The error bound of the returned value is 1.0 ULP.
exp: These functions return the value of e raised to a. The error bound of the returned value is 1.0 ULP.
log: These functions return the natural logarithm of a. The error bound of the returned value is 1.0 ULP.
erf: These functions return the value as specified in the C99 specification of erf and erff functions. The error bound of the returned value is 1.0 ULP.
